Folder aset Jelajah IPS Kelas 8
================================
Letakkan gambar (PNG transparan disarankan) di folder berikut, lalu ubah
useImages menjadi true di assets.js. Gambar yang tidak ada otomatis diganti emoji.

players/      player1.png, player2.png          (karakter pemain, persegi ~256x256)
tiles/        start, finish, mudah, sedang, sulit, bonus, khusus  (.png, ~128x128)
buildings/    school.png                          (bangunan di tengah papan, ~400x400)
dice/         roll.png                            (ikon tombol dadu)
              face1.png ... face6.png             (opsional, muka dadu)
effects/      benar.png, salah.png, bonus.png     (ikon event di kartu soal)
ui/           sound_on.png, sound_off.png
background/   page.jpg (halaman), stage.jpg (belakang papan), board.jpg (tengah papan)

Mengganti nama/path file: ubah nilai img di assets.js. game.js tidak perlu diubah.
